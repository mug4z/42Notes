# Ex02 
## Specification
- input: at least 3000 different positive integers
- output: 
  1. Print unsorted sequence.
  2. Sorted sequence.
  3. Time of process by the first container.
  4. Time of process by the second container.
    - Precision of time must be able to see the difference clearly.
- error : Message on the stderr.
- container: deque, vector.
- implement with 2 different containers.

### Logic in main
- sort -> do the actual sorting
- timeTaken -> check the time the execution does.
#### Recursion
- Going down is create the pairs.
- Going up,  initialization and insertion.
### Logic of the PmergeMe class
- IN -> List of unorder number
-  isbigger -> make a comparaison in pairs or elements to find the biggest number.
- swap -> swap pairs or elements
- divide -> divide the element into new pair
	- if new divide cannot be made, the result is the actual pairing.
- OUT -> Sequence of number, accending
Methods:
- `bool isBigger(T);`
- `void swap(T pair);`
- `std::vector<PmgerMe::Pair<std::vector<int> > > divide(T pair);`
	- mergePair()
- `std::vector<PmgerMe::Pair<std::vector<int> > > divide(std::vector<int>);`
#### Merge the pair to make the pair of pair and so on
- make a pair of vector
- for the next level make a new pair that merge the a and b of the previous pair.
- and so on.
