## General Instructions
> [!important]-
> - Web Security
> - Credentials,API Key, are in .env that must be in the `.gititnore`
> 
- You may use micro-frameworks and any necessary libraries for this project.
- We define a “micro-framework” as one that includes a router and possibly templating but does not include an ORM, validators, or a User Account Manager.1 As long as you adhere to these constraints, you are free to use the tools of your choice.
- Your application must not produce any unexpected or unhandled errors on either the server-side or the client-side. Legitimate error cases must return appropriate HTTP status codes and must be handled gracefully (without exposing stack traces or breaking the UI).
- You must manually create your queries, like experienced developers do. However, if you’re clever, you can build your own library to simplify query management.
