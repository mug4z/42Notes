## ARP my friend
The arp is **stateless protocol**  meaning that it does not retain session state from previous request, all request can be understood as isolated.
## Meaning
ARP stands for **Address Resolution Protocol** 

## Goal
The goal of the attack is to link the attacker's MAC address to the target IP so any packet meant to this IP will pass through the attacker's machine, in a Local Area Network (LAN).

It is interesting to target the router as all the traffic go through it.
