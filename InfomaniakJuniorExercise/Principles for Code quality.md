
## Readability & clean code principles with Laravel
As the application is likely to grow with new features added, implement the **SoC** principle according to best pratices in Laravel ( or according to you )

If you already followed this principle there is nothing to change, ortherwise take a step back and think on how you can re-organise your code to produce a fully maintainable and easy to read code base.
